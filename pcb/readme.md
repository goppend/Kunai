## Prototype PCB
This is the first release of the Kunai PCB. It's a functional prototype, and as such isn't recommended for gaming yet.

A few things to keep in mind, for anyone interested in building one:
- I have no enclosure designed yet, but the general button layout is 1:1 with an original Dualshock 2.
- The rectangular connectors were for testing, to easily swap a pressure sensor from one spot to another. I would not recommend using these connectors and instead replace the footprint with a normal soldered footprint since that portion of the testing is complete.
